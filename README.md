Entry for the [make.fun bounty "The Printer Finally Answers"](https://make.fun/bounty/u-mang-the-printer-finally-answers-8fbf0907): one line of text, written as the office printer's own comeback to the paper jams, cryptic error codes and thumps.

> I did not jam — you loaded damp paper, thumped my side twice, and blamed the only machine here that prints your own mistakes back at you.

137 characters. Weary, literal, faintly passive-aggressive — flat device logic, exactly as a printer that has seen everything would say it.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (created if needed). Deterministic, no network, no external files.
